# hackathon-2026-track-3
Shared repository for components developed at the 3rd track of the 2026 hackathon (Your Health, Your Data — Building the Personal Health Dataspace)

# Getting started

1. Clone this repo
2. Add a folder to the root of the repo named after your component
3. Develop your component until it works with the components provided by other participants
4. Demo and enjoy :-)
